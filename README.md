## 📌 Repository Overview

This repository provides working HTML/CSS code samples for every essential CSS concept, ranging from basic box styling to advanced multi-dimensional CSS Grid layouts and 2D/3D animations.

### 🌟 Core Learning Modules
- 📦 **Box Model & Core Styling**: Margin, padding, borders, backgrounds, display modes, positioning, and CSS units.
- 🎯 **Advanced CSS Selectors & Pseudo-elements**: `:nth-child`, `:hover`, `:focus`, `::before`, `::after`, and attribute selectors.
- 📐 **Flexbox Engine**: `justify-content`, `align-items`, `flex-direction`, `flex-wrap`, and alignment logic.
- 🔲 **CSS Grid System**: Grid columns, rows, gaps, spanning, template areas, `autofit`, `minmax()`, and media queries.
- 🎬 **Animations, Transitions & Transforms**: `@keyframes`, `transition-duration`, `transform: rotate / scale / translate`.
- 📱 **Responsive Web Design**: Media queries (`@media`), fluid typography, and viewport relative units (`vw`, `vh`, `rem`, `em`).
- 🎨 **Modern UI Components & Effects**: Custom CSS variables (`var(--name)`), `box-shadow`, `text-shadow`, forms, tables, and buttons.
